# Saw it once, find it forever.

![A screenshot of the 'Memory Machine' app interface displaying a timeline of recorded screen activity with various thumbnails.](src/assets/hero.webp)

Memory Machine records your Mac's screen activity in the background, letting you instantly search and revisit anything you've seen. Everything stays local on your device. Memory Machine requires macOS 14.0 (Sonoma) or later.

Visit [memorymachine.app](https://memorymachine.app) to sign up for the preview release and get early access.
